# AI Emotion Detector

## About the Project

This project is an AI-powered web application that detects emotions from customer feedback written in natural language. It uses the Watson NLP Emotion Detection service to analyze text and identify five emotions: anger, disgust, fear, joy, and sadness. The application also determines the dominant emotion and presents the results through a simple Flask-based web interface.

This project was completed as part of the IBM course **"Build AI Applications with Python and Flask"**.

## Main Features

- Detects emotions from customer feedback in text format.
- Identifies:
  - Anger
  - Disgust
  - Fear
  - Joy
  - Sadness
- Determines the dominant emotion.
- Provides results through a web interface using Flask.
- Handles blank or invalid input with an appropriate error message.
- Includes unit testing using Pytest.
- Uses Pylint for static code analysis.
- Can be run locally through IBM Cloud IDE.

## Tech Stack

- **Python** – Application development and backend logic
- **Watson NLP** – AI-based emotion detection
- **Flask** – Web application framework
- **Requests** – Communication with the Watson NLP service
- **Pytest** – Unit testing
- **Pylint** – Static code analysis
- **HTML, CSS & JavaScript** – Web interface
- **IBM Cloud IDE** – Development and deployment environment
- **Git & GitHub** – Version control and project hosting
